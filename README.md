### 2. หลังบ้านแอดมิน (Admin Back-end)
- **ทางเข้าลับด้วยโค้ด**: เข้าผ่าน URL `/secret-admin` กรอกรหัส **`ImatchaU`** ปลดล็อกสิทธิ์แอดมินทันที
- **แดชบอร์ดสรุปยอด**: รายได้รวมที่อนุมัติแล้ว, จำนวนออเดอร์, จำนวนสมาชิก, แจ้งเตือนสินค้าสต็อคต่ำ
- **ระบบจัดการสต็อค**: ตรวจสอบสต็อคคงเหลือ, เติมสต็อคสินค้าเดิม, เพิ่มสินค้าใหม่
- **ระบบตรวจสอบสลิปและคำสั่งซื้อ**: ตรวจสอบยอดเงิน, กดดูรูปสลิปขยายขนาดใหญ่, ปรับสถานะชำระเงิน และสถานะจัดส่ง
- **ระบบแจกแต้มอัตโนมัติ**: เมื่อปรับสถานะจัดส่งเป็น "จัดส่งสำเร็จ (completed)" ระบบจะเพิ่มแต้มสะสมให้ลูกค้าตามจำนวนแก้วน้ำในออเดอร์ทันที

1. เปิด Terminal และเข้าไปที่โฟลเดอร์ของระบบใหม่:
   ```bash
   cd "/Users/ramita/Documents/I wendy Matcha/matcha_online_system"
   ```

2. รันแอปพลิเคชัน Flask:
   ```bash
   python3 app.py
   ```

3. เปิดเว็บเบราว์เซอร์ไปที่:
   ```text
   http://127.0.0.1:5050
   ```
